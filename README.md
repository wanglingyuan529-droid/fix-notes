# fix-notes

个人报错排障流水账：遇到什么问题、怎么定位、怎么解决、下次怎么避免。
按类别归档——每个分类一个文件夹，文件夹内的 README 就是该分类的索引。

## 分类

| 分类 | 说明 | 记录数 |
|---|---|---|
| [网络](网络/) | 网络连接、认证、代理、防火墙相关 | 2 |
| [代码](代码/) | 代码 bug、安装部署、开发环境相关 | 2 |
| [系统](系统/) | 系统安装、磁盘分区、引导、双系统相关 | 1 |

## 记录规则

1. 每条记录一个文件：`<分类>/YYYY-MM-DD_主题.md`
2. 统一结构：**现象 → 根因 → 修复 → 验证 → 教训**
3. 新增记录做两件事：写文稿 + 在所属分类的 README 索引表加一行
4. 遇到新类别：建新文件夹 + 在本 README 的分类表加一行
